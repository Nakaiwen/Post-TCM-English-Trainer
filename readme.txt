社畜英語訓練手冊 / Office English Survival Handbook
====================================================

版本：VOL. II
類型：純前端英文學習工具
主檔案：index.html
語言：繁體中文介面 + 英文職場句型

----------------------------------------------------
1. 專案簡介
----------------------------------------------------

《社畜英語訓練手冊 / Office English Survival Handbook》是一款以職場英文為主題的互動式學習工具。
它用復古紙本訓練教材的視覺風格，將常見辦公室英文句型、商務黑話、情境應答與跟讀練習整合在單一 HTML 頁面中。

工具的核心目標不是讓使用者死背文法，而是幫助使用者快速理解英文職場語境中的「表面意思」與「真正含意」，並學會在尷尬、催促、拒絕、澄清、推進決策等情境中，使用更自然且得體的英文回應。

----------------------------------------------------
2. 主要功能
----------------------------------------------------

2.1 每日金句

顯示一組職場英文句型，包含：

- 英文句子
- 中文翻譯
- 使用情境
- 言外之意
- 實戰對話
- 單句播放發音
- 整段對話播放
- 下一句切換
- 收藏功能

範例句型包含：

- Let's circle back on this.
- Per my last email...
- Just a gentle reminder...
- Could you loop me in on this?
- I don't have the bandwidth right now.

2.2 黑話翻譯機

整理常見辦公室英文黑話，將「他們嘴上說的話」翻譯成「實際想表達的意思」。

每筆資料包含：

- 英文黑話
- 中文表面意思
- 真正含意

使用者可以透過搜尋欄輸入關鍵字，例如：

- circle back
- gentle reminder
- loop in
- noted
- FYI

系統會即時篩選相關內容。

2.3 情境快問

以中文職場情境作為題目，讓使用者從多個英文回應中選出最合適的一句。

功能包含：

- 題目情境說明
- 多選題回答
- 答對 / 答錯即時顯示
- 正解講評
- 跟讀練習
- 下一題
- 從頭再來
- 答對、答錯、準確率統計
- 重置分數

2.4 我的收藏

使用者可以在「每日金句」中收藏想複習的句子。
收藏後可在「我的收藏」頁籤集中查看。

每張收藏卡會顯示：

- 英文句型
- 中文意思
- 言外之意
- 發音播放按鈕
- 移除收藏按鈕

2.5 語音播放與跟讀

本工具使用瀏覽器內建的 Web Speech API / SpeechSynthesis 功能進行英文發音播放。

支援：

- 每日金句單句播放
- 對話逐句播放
- 對話播放時高亮目前句子
- 黑話項目播放
- 測驗正解跟讀
- 收藏句型播放
- 發音速度切換：慢速、正常、流暢

若瀏覽器不支援語音合成，頁面會顯示提示，建議使用 Chrome、Safari 或 Edge。

----------------------------------------------------
3. 操作方式
----------------------------------------------------

1. 直接用瀏覽器開啟 index.html。
2. 進入頁面後，預設顯示「每日金句」。
3. 點擊上方頁籤切換功能：

   - 每日金句
   - 黑話翻譯機
   - 情境快問
   - 我的收藏

4. 在「每日金句」中：

   - 點擊「下一句 NEXT」切換句型。
   - 點擊喇叭圖示播放英文發音。
   - 點擊「播整段對話」播放完整情境對話。
   - 點擊「★ 收藏」儲存句型。

5. 在「黑話翻譯機」中：

   - 輸入關鍵字即可搜尋職場黑話。

6. 在「情境快問」中：

   - 讀取中文情境。
   - 選出最得體的英文回應。
   - 查看講評與正解。
   - 使用跟讀功能練習正確句型。

7. 在「我的收藏」中：

   - 查看已收藏句型。
   - 播放收藏句型發音。
   - 移除不需要的收藏。

----------------------------------------------------
4. 技術架構
----------------------------------------------------

本工具為單檔純前端專案，主要由以下部分組成：

- HTML：頁面結構與四大功能面板
- CSS：復古紙本文書風格、響應式版面、互動狀態
- JavaScript：資料渲染、頁籤切換、測驗邏輯、收藏、語音播放、狀態儲存

主要資料陣列：

- PHRASES：每日金句資料
- DECODER：黑話翻譯機資料
- DRILLS：情境快問題庫

主要狀態：

- currentPhraseIdx：目前每日金句索引
- currentDrillIdx：目前測驗題目索引
- favorites：收藏句型集合
- score：測驗分數，包含 correct 與 wrong
- speechRate：語音播放速度

----------------------------------------------------
5. 狀態儲存
----------------------------------------------------

工具會透過 window.storage 儲存使用者狀態。

目前儲存項目包含：

- favorites：已收藏句型
- score：情境快問答對 / 答錯紀錄
- speechRate：使用者選擇的發音速度

如果執行環境沒有 window.storage，工具仍可正常使用，只是不會保存狀態。

----------------------------------------------------
6. 瀏覽器支援
----------------------------------------------------

建議使用下列瀏覽器：

- Google Chrome
- Microsoft Edge
- Safari

語音播放功能依賴瀏覽器是否支援 SpeechSynthesis。
不同瀏覽器與作業系統可用的英文語音可能略有差異。

----------------------------------------------------
7. 視覺設計特色
----------------------------------------------------

本工具採用復古辦公室文件 / 機密訓練手冊風格。

設計元素包含：

- 米色紙張背景
- 紙張紋理與陰影
- 打字機式小字標籤
- 紅色章戳感強調色
- Serif / Sans / Mono 字體混搭
- 文件編號、日期、版本資訊
- 類似內部流通文件的版面語氣

整體風格兼具學習工具與惡趣味職場諷刺感。

----------------------------------------------------
8. 響應式設計
----------------------------------------------------

頁面支援桌機與手機瀏覽。

在較小螢幕上會自動調整：

- 頁面邊距
- 標題大小
- 頁籤間距
- 每日金句雙欄改為單欄
- 黑話翻譯機項目改為直向排列
- 收藏卡片改為單欄

----------------------------------------------------
9. 如何新增內容
----------------------------------------------------

9.1 新增每日金句

在 JavaScript 的 PHRASES 陣列中新增一筆物件：

{
  en: "英文句型",
  zh: "中文翻譯",
  context: "使用情境",
  subtext: "言外之意",
  dialogue: [
    ["A", "對話第一句"],
    ["B", "對話第二句"]
  ]
}

9.2 新增黑話翻譯

在 DECODER 陣列中新增：

{
  said: "英文黑話",
  saidZh: "中文表面意思",
  meant: "真正含意"
}

9.3 新增情境快問題目

在 DRILLS 陣列中新增：

{
  situation: "中文情境描述",
  options: [
    { text: "選項 A", correct: false, why: "講評" },
    { text: "選項 B", correct: true, why: "講評" },
    { text: "選項 C", correct: false, why: "講評" },
    { text: "選項 D", correct: false, why: "講評" }
  ]
}

每題建議只有一個 correct: true 的選項。

----------------------------------------------------
10. 注意事項
----------------------------------------------------

- 本工具為靜態網頁，不需要後端伺服器。
- 若直接用本機瀏覽器開啟即可使用大部分功能。
- 語音功能取決於瀏覽器與系統語音支援。
- 收藏與分數若無 storage 支援，重新整理後可能不會保留。
- 所有學習內容偏向幽默化與情境化，適合用於職場英文語感訓練，不建議當成正式商務英文唯一標準。

----------------------------------------------------
