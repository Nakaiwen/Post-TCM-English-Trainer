Vocabulary Practice 後中醫英文單字練習器
README

版本說明
------------------------------------------------------------
本專案是一個純前端的英文單字練習器，主題為「後中醫英文單字練習」。
目前程式集中在單一檔案 index.html，可直接用瀏覽器開啟使用，不需要後端伺服器、不需要資料庫，也不會把學習資料上傳到網路。

主要用途
------------------------------------------------------------
1. 練習後中醫、醫學英文與學術英文常見單字。
2. 透過句子填空、段落填空、同義/反義字、混淆字辨義與考古題單字模式，加強字義、語境與辨析能力。
3. 在本機瀏覽器記錄答題表現，追蹤今日題數、正確率、已練字數、已熟練字數與需要加強的單字。

檔案結構
------------------------------------------------------------
index.html      主程式檔案，包含 HTML、CSS、JavaScript 與字彙資料。
readme.txt      本說明文件。

系統需求
------------------------------------------------------------
建議使用下列任一現代瀏覽器：
- Google Chrome
- Microsoft Edge
- Safari
- Firefox

發音功能使用瀏覽器內建的 Web Speech API。若瀏覽器或裝置不支援 speechSynthesis，練習器仍可使用，但發音功能可能無法播放。

安裝與啟動方式
------------------------------------------------------------
方式一：直接開啟
1. 將 index.html 放在電腦或手機可存取的位置。
2. 用瀏覽器開啟 index.html。
3. 進入首頁後，選擇練習模式即可開始。

方式二：放到網站空間
1. 將 index.html 上傳到網站主機或靜態網頁空間。
2. 使用瀏覽器開啟該頁面網址。
3. 不需額外安裝套件。

練習模式
------------------------------------------------------------
MODE 01 句子填空 / Sentence Cloze
在例句中挖空關鍵字，從 4 個選項中選出最符合語境的單字。

MODE 02 段落填空 / Passage Cloze
模擬醫學、科學或學術閱讀情境，在短文中完成多個空格。目前內建 6 篇段落題。

MODE 03 同義 / 反義字 / Synonym & Antonym
給定目標字，從 4 個選項中選出同義字或反義字，訓練字彙網絡與語意辨識。

MODE 04 混淆字辨義 / Confused Pairs
針對形近、音近或意義容易混淆的單字組進行辨義訓練。目前內建 11 組混淆字說明。

MODE 05 考古題單字 · 強化訓練 / Past Exam Vocabulary
只練習曾標記為中國醫或義守醫考古題來源的單字，題型會隨機混合句子填空與同義/反義字。目前內建 149 個考古題標記單字。

內建字彙資料
------------------------------------------------------------
目前 index.html 內建約 686 筆字彙資料。
每筆單字資料可能包含：
- w：英文單字
- p：詞性
- z：中文解釋
- e：英文例句
- d：衍生字
- s：同義字
- a：反義字
- c：容易混淆的對照字
- src：考古題來源標記

學習紀錄與資料儲存
------------------------------------------------------------
本練習器使用瀏覽器 localStorage 儲存學習進度與設定。

使用的 localStorage key：
- hzy_vocab_v1：學習紀錄
- hzy_vocab_settings_v1：練習設定

記錄內容包含：
- 每個單字的看過次數
- 答對次數
- 答錯次數
- 最近練習時間
- 複習排程
- 每日練習統計

注意：
1. 學習資料只存在目前使用的瀏覽器與裝置中。
2. 清除瀏覽器資料、更換瀏覽器或使用無痕模式，可能會導致紀錄消失。
3. 可使用「匯出進度」備份學習資料，再於其他裝置或瀏覽器使用「匯入進度」恢復。

設定功能
------------------------------------------------------------
首頁點選「設定」可調整：
- 每日題數：預設 20 題，可設定 5 到 100 題。
- 發音語速：慢、適中、標準。
- 每題完成後自動讀音：可開啟或關閉。
- 清除所有學習進度：會刪除本機儲存的學習紀錄，且無法復原。

匯出與匯入進度
------------------------------------------------------------
匯出進度：
點選首頁「匯出進度」，系統會下載一份 JSON 檔，例如：
後中醫單字學習進度_YYYY-MM-DD.json

匯入進度：
點選首頁「匯入進度」，選擇先前匯出的 JSON 檔，即可恢復學習紀錄與設定。

維護與修改字彙
------------------------------------------------------------
若要新增或修改單字，請打開 index.html，找到 JavaScript 區塊中的：

const VOCAB = [ ... ];

新增資料格式範例：
{w:"example",p:"n.",z:"例子",e:"This is an example sentence.",s:"sample",a:"counterexample"}

常用欄位說明：
- w 必填：英文單字。
- p 建議填寫：詞性，例如 n.、v.、a.、adv.。
- z 必填：中文解釋。
- e 建議填寫：英文例句，句子填空模式會使用。
- s 選填：同義字。
- a 選填：反義字。
- c 選填：混淆字對照。
- src 選填：考古題來源，例如 "中國醫106"、"義守醫110"。

若要新增段落填空題，請修改：
const PASSAGES = [ ... ];

若要新增混淆字說明，請修改：
const CONFUSED_NOTES = { ... };

開發注意事項
------------------------------------------------------------
1. 本專案目前是純前端單檔架構，部署簡單，但資料與程式碼都寫在 index.html 裡。
2. 修改 JavaScript 後，建議先用瀏覽器開啟測試首頁、各練習模式、設定、匯出與匯入功能。
3. 若未來字彙量繼續增加，可考慮將 VOCAB、PASSAGES、CONFUSED_NOTES 拆成獨立 JSON 檔，方便維護。
4. 若要放到正式網站，建議保留 UTF-8 編碼，避免中文與特殊符號顯示異常。
5. 本工具偏向學習輔助，不應取代正式教材、考古題詳解或教師講義。

常見問題
------------------------------------------------------------
Q1：為什麼發音沒有聲音？
A：請確認瀏覽器支援 Web Speech API，並檢查裝置音量與瀏覽器播放權限。有些瀏覽器需要使用者先點擊頁面後才允許播放語音。

Q2：換電腦後進度不見了？
A：進度儲存在原本裝置的瀏覽器 localStorage。請在原裝置先匯出進度，再到新裝置匯入。

Q3：清除瀏覽器快取會不會影響進度？
A：若清除項目包含網站資料或 localStorage，可能會刪除進度。建議定期匯出備份。

Q4：可以離線使用嗎？
A：可以。index.html 本身可離線開啟。不過字型來自 Google Fonts，離線時可能改用系統預設字型；發音功能也可能因瀏覽器與語音包狀態而有所差異。

Q5：可以上傳到 GitHub Pages 嗎？
A：可以。此工具是靜態網頁，適合部署到 GitHub Pages、Netlify、Vercel 或一般靜態主機。

建議使用流程
------------------------------------------------------------
1. 每天先做 MODE 01 句子填空，建立單字語感。
2. 再做 MODE 03 同義/反義字，加強橫向字彙連結。
3. 考前集中使用 MODE 05 考古題單字強化訓練。
4. 定期查看 Weak Words，把答錯率高的字另外整理複習。
5. 每週匯出一次進度，避免瀏覽器資料遺失。
